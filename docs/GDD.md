# 游戏设计文档（GDD）v1

《零下三十 / Thirty Below / 영하 삼십》（暂名）。核心决策见 `PLAN.md §0`，叙事与道德系统见 `NARRATIVE.md`，具体数值与内容表见 `CONTENT.md`。

## 1. 游戏设计概要

### 1.1 世界观

- **地点**：明尼苏达州虚构小镇"哈洛瀑布（Harlow Falls）"，人口原约 9000。
- **时间**：寒潮来袭后第 6 个月的深冬。常态室外 −15 °C 上下，小寒潮 −30 至 −40 °C，最终的大寒潮更低。
- **势力**：
  - 平民住户（各自为战的家庭和独居者）
  - 圣马可教堂互助会（和平社区，可交易）
  - 流动商贩
  - 掠夺者团伙
  - "基洛哨站"（Checkpoint Kilo）：占据县政府地下民防掩体的国民警卫队残部，有物资也有腐败。

### 1.2 单局结构（30 天，三幕）

| 幕 | 天数 | 主题 | 节拍 |
|---|---|---|---|
| 一 | 1–10 | 安顿：整理房子、修好第一台加热器、认识街区 | 第 1 次小寒潮（第 6–9 天随机） |
| 二 | 11–20 | 稀缺：近处搜刮殆尽，必须走远、交易或下手；后果开始回头找上门 | 第 2 次小寒潮（第 13–17 天）；哨站主线开放 |
| 三 | 21–30 | 清算：为大寒潮做准备，决定去留 | 第 3 次小寒潮（第 21–24 天，约 60% 概率出现）；大寒潮第 28–30 天 |

寒潮的日期和强度每局随机，由无线电提前预报，预报的提前量和准确度取决于无线电等级。

### 1.3 一天的流程

| 时段 | 游戏时间 | 现实时长 | 玩法 |
|---|---|---|---|
| 白天 | 06:00–19:00 | 最长 13 分钟，可提前结束 | 家中实时管理全员；可派 1–2 人去白天地点交易（路上耗时，家里时间照常流逝） |
| 黄昏 | 19:00–21:00 | 不计时的安排界面 | 分配晚餐；给每人指定夜间角色：外出 / 守夜 / 睡觉；选目的地与携带物 |
| 夜晚 | 21:00–05:00 | 最长 8 分钟 | 外出小队的潜行副本（往返路程从 8 小时里扣）；无人外出则快速结算到天亮 |
| 黎明 | 05:00–06:00 | 报告界面 | 夜间报告（家里是否被袭、收获、伤情、情绪变化、广播），自动存档 |

- 暂停随时可用（家里和副本都可以），暂停时可以下指令。速度档：家园 ⏸ / 1× / 2× / 4×，潜行只有 ⏸ / 1×；D7 的"1 秒 = 1 分钟"指 1×；打开轮盘或菜单时自动暂停（PLAN §10 U4、U11）。
- 迟归：HUD 始终显示"最晚撤离时间"（05:00 减去回程时间）。超时到家的人按迟到时长受罚：冻伤或力竭造成的轻伤至中伤、疲劳清零、有概率触发路遇巡逻的事件。
- 寒潮当天：室外极寒，夜间外出需要高级御寒装备，否则持续掉体温。

### 1.4 角色

**属性**（0–100，除特别说明外越高越好）：饱食、水分、体温、精力、心理。另有：

- 伤势：部位无关的三级制，轻伤 / 重伤 / 濒死，影响速度、负重和工作效率。
- 疾病：感冒、肺炎、冻伤、食物中毒。
- 心理状态：稳定 → 动摇 → 低落 → 抑郁 → 崩溃（NARRATIVE §2.6）。
- 价值观向量（NARRATIVE §2.4）：决定此人对团队行为的反应。
- 关系：与每位队友的亲疏值。

### 1.5 家园

一栋美式单层住宅加车库和院子，约 30×24 格，3 套布局每局随机一套。

- **整理**：开局多数房间是废墟（瓦砾挡路）。清理要时间和工具，产出木料/废料，瓦砾和院子雪堆里有概率挖出罐头等物资。
- **破损**：墙洞和破窗漏热、降低防御。可以钉板封堵，再升级为保温层。
- **温度模型**（纯 Lua，按房间）：每个房间是一个节点，和室外、相邻房间之间有导热系数（由破损、保温、门的开闭决定）；加热器给所在房间供热，每个人也贡献少量体热。结果是玩家会主动关门、封房间、把人聚到一间屋里取暖。
- **湿度模型**（全屋一个值）：加热器使空气变干，加湿器和烧水加湿。理想区间 40–60%。过干则呼吸道疾病概率上升、睡眠变差；又湿又冷则结霜、保温层受损。
- **电力与燃料**：发电机（汽油）或蓄电池组供电给电暖器、加湿器、无线电和灯；丙烷加热器、柴火炉是不用电的替代路线。烧家具和书能取暖，但对部分角色扣心理。
- **防御**：门窗加固、绊线警报、守夜人数与武器，共同决定夜袭的结果。
- **新增机制与开局状态**（CONTENT §2.1、§5.2、§5.5、§10.2，PLAN §10 C3、C4）：熟食 36 小时变质；发电机与柴火炉的烟柱会提高夜袭概率；储水罐在 0 °C 以下冻结。开局只有灶可用，发电机损坏，前三天靠灶和封窗度过。

### 1.6 科技树（4 条分支 × 3 层，约 40 个节点）

解锁条件 = 工作台等级 + 材料 + 部分节点需要在副本里找到的图纸（每局能找到哪些不同）+ 个别节点是角色专属。专属节点缺人时成本与工时 ×1.5；图纸投放为必出 3 张 + 其余各 65%（详见 CONTENT §4）。

| 分支 | 一层 | 二层 | 三层 |
|---|---|---|---|
| 生存 | 简易灶、融雪桶、储水罐 | 改良灶、滤水器、捕鼠笼、芽菜盘 | 蒸馏器（酿酒，可交易）、烟熏架、代用咖啡烘焙 |
| 保暖 | 清理工具、钉板封窗、床铺 | 修复电暖器、加湿器、保温层 I | 柴火炉改造、保温层 II、避寒小间（大寒潮用） |
| 工坊 | 工作台 I、撬棍、铲子、简易背包 | 工作台 II、撬锁工具、近战武器、雪橇、冬装 I | 工作台 III、消音手段、陷阱、冬装 II、修车（南行结局） |
| 信号与电力 | 修复收音机（1 天预报） | 天线（3 天预报、商贩行程）、发电机、灯 | 蓄电池组、短波（哨站频率、远处消息） |

### 1.7 物品与交易

- **物品大类**：食物（罐头、生食、熟食）、水、燃料（木料、汽油、丙烷）、材料（废料、零件、电子元件、布料）、药品（绷带、抗生素、止痛药）、奢侈品（咖啡、酒、香烟、书）、工具、武器弹药、图纸、剧情物品。
- **新机制**：熟食 36 小时变质（见 CONTENT §2.1；开局状态同 §1.5：只有灶可用，发电机损坏）。
- **以物易物**：没有货币。每件物品有基础价值；商贩类型、天数、势力声望和谈判者的特长会调整买卖价差。奢侈品和药品的价值随天数上涨。
- **交易机会不是每天都有**：流动商贩按随机日程上门（无线电二级后可预知）；白天可去的交易地点每局只有 2–3 个；声望太差会被赶走。

### 1.8 大地图与副本生成

- **大地图**是节点图，不是可自由行走的地图。每局从约 18 种地点原型里抽 12–14 个，按进度解锁：第 1 天开放最近的 3 个，其余通过天数、无线电消息、探索时找到的线索和事件逐步出现。
- **地点原型**（每个地点的详述见 WORLD §6，数值指向 CONTENT §9）：超市、药房、加油站、五金店、郊区住宅（有住户）、独居老人的房子、教堂互助会、学校、诊所、仓库（掠夺者据点）、农场、电台塔、汽车旅馆、拖车营地集市、建筑工地、警察局、河边码头、基洛哨站。
- **每个地点的随机维度**：占用状态（空置 / 平民 / 商贩 / 敌对）、2–3 套手工布局模板里抽一套、容器里的战利品、NPC 的位置和日程、上锁的门。
- **预算制平衡**（回应"资源获取预期相对平衡"）：每一幕对每类资源（食物、水、燃料、零件、药品、奢侈品、武器）有一个总预算。生成器先随机抽地点，再把预算按地点的"类型权重 × 危险度"分配到容器里，并校验每幕每类总量落在目标的 ±10% 内，不合格就重抽。这样每局"哪里有什么"不同，但"总共能拿到多少"相近；高危地点单位时间收益更高。
- **白天访问**：不能进室内。在门口与住户/商贩交易或对话，对方可能因声望或过往行为拒绝、驱赶。
- **夜晚访问**：有撬锁工具或撬棍才能进室内，进入潜行模式。

### 1.9 夜间潜行

- **感知三要素**：
  - 视线：NPC 有带朝向的视锥，夜里距离缩短，黑暗处更难被看见，手电会暴露自己。
  - 噪音：走/潜行/跑、不同地面（雪地、木地板、碎玻璃）、撬门、搜刮、打斗、枪声各有传播半径，墙体会衰减。
  - 光：灯、炉火、手电。
- **NPC 状态机**：睡眠/日常 → 起疑（去声源查看）→ 警觉（搜索）→ 敌对（攻击）或恐惧（逃跑、躲藏、求饶、呼救）。平民和掠夺者的分支不同。
- **交互**：
  - 撬锁：安静但慢。
  - 撬棍破门：快但响。
  - 搜刮容器：有进度条，会发出声音。
  - 背后制服：可选打晕或杀死，后果不同。
  - 亮武器威吓：平民做服从判定。
- **小队**：切换操控；队友指令有跟随、原地待命、望风（发现动静会提示）、搬运。两个人背包多一倍，但噪音更大、家里少一个守夜的。
- **撤离**：到出口区域并确认。背包有容量上限，逼玩家取舍。

### 1.10 战斗与伤亡

- 实时进行，可暂停下指令。近战有拳、刀、棍、撬棍、斧；远程有手枪、霰弹枪、猎枪，弹药极少，开枪会惊动整张图。
- 打击感沿用 `delve-dev` 技能 §10 的参数（顿帧、trauma 震屏、闪白、粒子），强度调低到与写实基调相称。玩法随机数与特效随机数分开。
- 伤势三级；濒死倒地后有短暂的救援窗口。主角团成员会死，死亡是永久的。
- 每一次伤亡，无论是自己人还是 NPC，都写入行为账本并触发后果（NARRATIVE §2）。

### 1.11 基洛哨站主线

哨站内部有两个人物：还想维持纪律的中尉，和靠倒卖物资发财的军士。时间节点：第 11 天开放，第 21 天决定庇护，第 27 天入住（早于第 28–30 天的大寒潮；详见 WORLD §7，PLAN §10 W5）。三个阶段：

1. **接触**：短波找到频率，或在路上被巡逻队拦下，或由 grace 引荐。
2. **证明价值**：交付物资（燃料、药、酒）、替他们办事（取回物资、修发电机、救治伤员），也有脏活（告发邻居的存粮、替军士运私货）。
3. **庇护资格**：名额有限，可能只收一部分人；可以多付代价换全员；军士一线可能收了东西却翻脸，除非手里有他的把柄。也可以反过来夜袭哨站仓库，这是全游戏最难的副本。

### 1.12 结局

| 结局 | 条件 | 变体 |
|---|---|---|
| 守住家 | 在家熬过第 28–30 天的大寒潮 | 按幸存人数、房屋状态、邻里存亡分支 |
| 地下 | 取得哨站庇护 | 全员 / 部分入内；走中尉线或军士线；被出卖 |
| 南行 | 第 25 天后修好车并备足燃料离开 | 带走谁、留下谁 |
| 失败 | 全员死亡或离队 | — |

每个结局之后是逐角色的尾声，以及"你做过的事"的回顾：哪些住户因你而死、因你而活。

### 1.13 局外进度

通关或失败后解锁图鉴条目、新的开局情境（例如"三人开局""深冬开局"）和难度修正项。不提供影响数值的永久强化。

## 3. 输入系统

### 3.1 结构

```
设备原始输入（键盘 / 鼠标 / 手柄）
      ▼
动作映射（core/input.lua）：绑定表把原始输入翻译成"动作"
      ▼
上下文栈：模态对话框 > 面板 > 副本 / 家园 / 大地图 > 全局
      ▼
场景和 UI 只读动作，不读原始按键
```

- 游戏逻辑只认动作名（如 `confirm`、`interact`、`sneak_toggle`），不出现具体按键。
- 绑定表保存在 `saves/settings.sav`，三套设备各有默认值，可在设置里改键，同一上下文内检测冲突。
- 记录"最近使用的设备"，界面上的按键提示图标随之切换；屏幕底部有一条上下文提示栏，列出当前可用的动作和对应按键。

### 3.3 纯鼠标

- 所有动作在屏幕上都有可点的入口：HUD 按钮、头像、右键菜单、快捷栏。
- 不依赖滚轮（框架本来也没有滚轮事件）：列表用可拖的滚动条和翻页箭头，缩放用 HUD 按钮。
- 提供"单键模式"选项：左键点地面即移动，长按代替右键。

### 3.4 纯手柄

- 键盘与手柄共用焦点目标算法（UI-UX §5.2、§6，PLAN §10 U7）。
- 世界里：左摇杆直接走；面前最近的可交互物自动成为"焦点目标"并高亮，A 交互、X 打开指令轮盘。
- 需要点任意位置时：按住 LT 进入自由光标，左摇杆移动光标，A = 左键、X = 右键。
- 界面里：所有可点的控件自动可聚焦，十字键/左摇杆按方向跳到最近的控件，LB/RB 切换页签。这要求 UI 库从第一天就内置焦点导航（PLAN §4.3 `ui/focus.lua`，规格见 UI-UX.md），不能事后补。

### 3.5 验收

- 三份探针脚本分别只注入键盘、只注入鼠标、只注入手柄事件，各自完成"新开一局 → 白天做一件物品 → 黄昏派人 → 夜里搜一个容器并撤离 → 黎明报告"的完整循环。
- 输入覆盖校验：每个动作要么三种设备都有绑定，要么有屏幕入口；每个界面里的每个控件都能通过焦点导航到达。

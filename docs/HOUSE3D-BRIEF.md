# 室内 3D 建模需求：ranch_a 三层住宅（B1 / 1F / 2F）

> 用途：交给人工或 AI 建模（Blender、Blender MCP、Meshy / Hunyuan3D / TRELLIS 等）。
> 视角方案已定：A（单层显示 + 楼层切换）+ C（其它层人物轮廓）。模型必须支持“只显示某一层 + 矮墙剖切”。
> 人物不建模：游戏里角色是竖直 billboard 精灵。预览图里放身高参考小人即可，不导出。

## 1. 全局规格

| 项 | 规定 |
|---|---|
| 单位 | 1 Blender unit = 1 m = 游戏 1 格 |
| 平面 | 20 列（x）× 14 行（y），外墙包含在内 |
| 坐标 | 网格 (列 c, 行 r) 的格子中心 = Blender `(c + 0.5, -(r + 0.5), z)`。即 +X 向东，行号向南增大对应 −Y。glTF 导出（Y-up）后正好是 X = 列，Z = 行，Y = 高 |
| 层高 | B1 地面 z = −3.0；1F 地面 z = 0；2F 地面 z = 3.0。楼板厚 0.3（楼板顶面 = 该层地面） |
| 墙 | 厚 0.2，沿格子中线走；1F / B1 墙高 2.7；外墙比内墙厚可以，但中线不变 |
| 门 | 宽 1 格（净宽 0.9），高 2.1；门扇单独对象，可开关（绕铰链轴旋转） |
| 窗 | 宽 1 格，窗台 0.9，窗顶 2.1；B1 只有高窗：窗台 2.1，窗顶 2.6 |
| 楼梯 | 每段 2 格宽 × 5 格长，15 级，每级高 0.2、深 0.33；带扶手 |
| 风格 | 低多边形，flat shading，无贴图、无法线贴图；材质只设 Base Color（必要时 Emission），名字用色卡名（例：`wood_3`） |
| 面数 | 全屋 ≤ 30k 三角面；单件家具 ≤ 600；瓦砾每堆 ≤ 150 |
| 原点 | 整栋房子的原点在网格 (0,0) 外角，即 Blender 世界原点；所有对象 Apply Transforms |

## 5. 结构与命名（剖切显示的关键）

- Collection：`B1`、`F1`、`F2`、`ROOF`、`REF`（参考小人和相机，不导出）。
- 每层：
  - `<层>_floor`：该层楼板（含楼梯开洞）。
  - `<层>_wall_low`：所有墙 0 → 1.2 m 部分，合并成一个对象。
  - `<层>_wall_high`：所有墙 1.2 m → 层高部分（门洞、窗洞在两段里都要正确开）。
  - 2F 的矮墙整体 1.0 m，只有 `F2_wall_low`；隔墙高于 1.2 m 的部分进 `F2_wall_high`。
  - `<层>_ceiling`：可省略（上层楼板底面就是天花板）。
- 家具、门、窗、瓦砾：每件一个对象，名字照 §4；有“熄灭 / 燃烧”两态的，做成 `_off` / `_on` 两个对象叠在同一位置。
- 不要合并家具到墙体；不要用修改器留到导出（导出前 Apply）。

## 6. 导出与预览图

### 导出

- `house.blend`（源文件）。
- `house_full.glb`：全部 Collection（除 `REF`）。
- `floor_B1.glb`、`floor_1F.glb`、`floor_2F.glb`：每层单独导出，坐标不变（不要归零），这样引擎可以直接叠放。
- glTF 设置：+Y Up（默认）、Apply Modifiers、只导出 Mesh、包含材质、不含相机和灯光。

### 预览相机（与游戏一致）

- 正交相机，Orthographic Scale ≈ 24。
- 旋转（Euler XYZ）：X = 60°，Y = 0°，Z = 45°。即从东南角（网格 (20,14) 一侧）斜向西北看，俯角 30°，与游戏的 yaw 45° / pitch 30° 相同。
- 目标点：房屋中心 (10, −7, 当前层地面 z)。
- 分辨率 1280×720。

### 渲染器

用 **Workbench**（不需要显卡，几秒一张）：Lighting = Flat 或 Studio、Color = Material、开 Cavity 和 Outline（描边色 `#0E1117`）。想看氛围可以另出一张 EEVEE（炉火用 Emission，冷色环境光 `ice_1`）。

## 7. 用 AI 生成单件道具时（Meshy / Hunyuan3D / TRELLIS）

只用于家具和道具；墙、楼板、楼梯请在 Blender 里按网格做，AI 生成的建筑结构对不齐格子。

提示词模板：

```
low-poly stylized game prop, {物体英文名}, {细节}, flat colors only, no textures,
muted cold-winter survival palette, worn and used, single object, centered,
real-world scale about {宽}×{深}×{高} m, under 600 triangles
```

例：`low-poly stylized game prop, cast-iron wood stove with stove pipe, small glass door, flat colors only, ... about 0.7×0.7×0.9 m`。

生成后在 Blender 里：缩放到 §4 尺寸；减面到预算以内；把材质替换成 §2 色卡里最接近的颜色。

### 9.2 通用手法

| 手法 | 做法 |
|---|---|
| 打破整齐 | 家具随机转 2–8°、偏移 5–15 cm；椅子拉出来；柜门、抽屉半开；地毯一角卷起 |
| 污渍和磨损 | 墙根 0.3 m 一圈暗色带（`concrete_2` / `wood_1`）；炉子后墙熏黑；门把手附近一块深色；地板走道磨浅（`wood_3` 的细长面片） |
| 寒冷 | 窗户玻璃内侧结霜（`snow_2` 面片盖住玻璃下半）；破窗下的地面有积雪和碎玻璃；外墙门缝塞毛巾；墙角挂冰凌 |
| 临时改造 | 窗户用塑料布 + 胶带封（半透明 `ice_4`）；门帘挂毯子挡风；床垫拖到客厅炉子旁 |
| 堆积 | 吃完的罐头堆、空水桶、脏碗；衣服搭在椅背上；纸箱塌了一半 |
| 叙事道具 | 墙上日历划掉的日子；手摇收音机；儿童画；家庭合照倒扣；手写的配给表 |

### 9.3 逐房间清单

**1F**

- 客厅：柴堆（`wood_2` / `wood_3` 原木 15–20 根，靠炉子右侧，这是玩法提示，必须醒目）；两张床垫拖到炉边 + 乱堆的毯子；晾衣绳横跨房间挂几件衣服；沙发上压着一床被子；地上一圈蜡烛头；墙洞 (17,0) 用木板和床单堵着，下面一小堆雪。
- 卧室：床被剥空，只剩床垫（被子都搬到客厅了）；衣柜门大开，衣服散在地上；窗户用书架顶住。
- 厨房：灶台上放锅、水壶；台面上空罐头和刀；水桶接融雪；冰箱门开着，里面空；桌上摊着配给表和半根蜡烛；地下室楼梯口旁边放手电。
- 工作间：工作台上拆开的零件、锯子、钉子盒；地上锯末和木屑；发电机旁边一桶空油桶；瓦砾堆旁扔着一把铁锹。

**B1**

- 锅炉间：地面一块油渍；墙上管道缠着保温布和胶带；扳手和水桶；墙上挂温度计。
- 地窖：一半架子空了；地上碎罐子；土豆箱见底；老鼠夹。
- 储藏间：拆开的木箱、撒出来的钉子；一卷塑料布；旧自行车。
- 避寒间：行军床上铺满毯子；墙上贴手绘地图和名单；几个空水壶；一个尿桶（加盖）；油灯是唯一光源。

**2F**

- 阁楼卧室：冷得没人睡，床上落了一层灰（`concrete_4` 薄片）；屋顶漏风处结霜。
- 儿童房：玩具散落；一只布偶被带下楼了，留下空位；墙上儿童画。
- 储物阁楼：圣诞装饰箱翻开；一部分保温棉已经被拆走（卷少了，地上有碎屑）；屋顶一处漏雪，下面放了盆。

### 9.4 外观顺带修正

- 外墙板读起来像玻璃幕墙：改成横向木挡板，颜色 `cloth_a_1` / `cloth_a_2` 交替，去掉蓝色反光感，减少横线数量。
- 屋顶加烟囱（客厅柴炉的烟道从屋顶穿出），冒一缕烟（`concrete_4` 低多边形）。
- 地面雪堆现在像石头：改成圆滑的雪坡，贴着墙根堆高 0.5–1 m，正门前有被铲开的小路。
- 屋檐下挂一排冰凌；车道上停一辆被雪埋了一半的皮卡（可选）。

### 9.5 注意

- Workbench 预览本来就是平光，会显得比游戏里干净。游戏里有逐顶点光照、昼夜压暗和像素化，最终效果以进引擎为准；但“东西太少、太整齐”这个问题光照救不了，必须靠这一轮。
- 装饰物不进碰撞和寻路，游戏逻辑仍然只看 §3 的网格；所以通道格不能放会让人以为走不过去的大件。

## 1. 原则

### 1.1 信息层级

| 层 | 内容 | 呈现 |
|---|---|---|
| L0 生死 | 濒死、被发现、寒潮来临、迟归倒计时 | 屏幕边缘色带 + 居中横幅 + 音效，持续到解除；不可被其它通知挤掉 |
| L1 时间与威胁 | 时钟、最晚撤离时间、天气与预报、潜行警戒等级 | 顶栏常驻，固定位置 |
| L2 队伍 | 头像条：需求条、状态图标、心理状态 | 左侧常驻 |
| L3 当前操作 | 选中角色详情、快捷栏、上下文提示栏 | 底部常驻 |
| L4 事件流 | 通知、日志 | 右上滚入、自动淡出；日志面板可回看 |
| L5 细节 | 工具提示、详情页、图鉴 | 悬停/聚焦/按键才出现 |

规则：任何时刻 L0–L2 不被面板盖住（模态对话框除外，且模态打开时游戏自动暂停）。世界画面是主体，常驻 HUD 占用面积 ≤ 25%。

### 1.2 视觉基调

- 废土写实：冷灰蓝底、霜白文字、锈红/琥珀只用于警示与强调。UI 面板像"磨损的金属牌与旧纸板"：深色半透明底、1 px 外描边、内侧 1 px 高光，**不用渐变、圆角、发光、投影模糊**。
- 与 Hi-bit 像素协调：全部图形按整数像素对齐，最近邻采样，用九宫格拉伸；文字烘焙像素字体；阴影只用 `ui.text_shadow(1,1,0,0,0,0.6)` 的硬阴影。
- 配色令牌（`ui/theme.lua`，取自 `wasteland.json` 最近色，实现时以色卡为准）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg` | `#1B1F24` α0.88 | 面板底 |
| `bg_hi` | `#262C33` α0.92 | 控件常态底 |
| `edge` | `#3A424A` | 描边 |
| `text` | `#E8ECEF` | 正文（对 `bg` 对比 ≥ 12:1） |
| `text_dim` | `#9AA4AD` | 次要（≥ 6:1） |
| `accent` | `#E8A63C` | 选中、强调、聚焦环 |
| `danger` | `#D8453A` | 危险、伤病 |
| `ok` | `#7FAE6A` | 良好 |
| `cold` | `#8FC3E0` | 寒冷、体温 |
| `disabled` | `#5B646C` | 禁用（带删除线图标，不只靠颜色） |

### 1.3 可读性

- 字体（`ui.font_load`，上限 8 个，用 6 个）：

| 名 | 标准模式 | 大字模式 | 用途 |
|---|---|---|---|
| `f_s` | 14 px | 18 px | 标签、需求条数值、提示栏、日志 |
| `f_b` | 16 px | 20 px | 正文、按钮、列表 |
| `f_t` | 24 px | 30 px | 标题、时钟、横幅 |

- **最小字号 14 px**（中文、韩文在该字号下可辨）；14 px 只用于次要信息，主要信息 ≥ 16 px。
- 对比度：正文 ≥ 4.5:1，次要 ≥ 3:1（装饰除外）。不仅靠颜色表达状态，必须叠加形状、图标或文字。
- 可点击目标 ≥ 32×32 虚拟像素；相邻目标间距 ≥ 4。
- **整数缩放**：`ui.set_scale(n)`，`n = max(1, floor(H/720))`（与世界 zoom 同式，ENGINE-PLAN A1 第 4 条）。虚拟屏幕 = 窗口 / n，最小 1280×720。1080p 下 n=1，虚拟屏 1920×1080：HUD 贴边锚定，居中面板限最大尺寸（§3.1）。窗口小于 1280×720 时进入"最小尺寸"：加黑边而不是缩小。
- 一切坐标用 8 px 网格；文字基线对齐到整数；半透明只用于面板底与覆盖层（`ui.color` 的 α）。

### 1.4 三语排版规则

1. **零字面文本**：界面里所有文字走 `i18n.t(key, params)`，不得在 `ui/*.lua` 与 `scenes/*.lua` 出现面向玩家的字符串。数字、单位、时间用格式化函数 `fmt.time(min)`、`fmt.temp(c)`（°C，三语相同）。
2. **留量**：按最长语言设计。经验系数（同字号下，以中文宽度为 1.0）：英文 1.2–1.5（长句 1.6）、韩文 1.2–1.4（韩文不按字断，只在空格断，行尾空白更大）。固定宽控件的文字区 = 中文文本宽 × 1.5，仍放不下则换行或省略，不缩字号。
3. **不写死宽度**：控件宽度 = `max(最小宽, text_measure + 左右内边距)`；容器用 `ui.text_measure(font,str,w)` 取行数后再定高度。按钮标签最多两行，高度随之增加。
4. **自动换行**：一律 `ui.text_box`/`text_wrap`；中文遵守禁则，英文按词，韩文按空格，超长词强制断（ENGINE-PLAN A1 第 17 条）。
5. **省略**：单行标签放不下时在末尾加 `…`（i18n 字符串里不含 `…`，由 `widgets.ellipsize()` 加）；可省略的元素必须在悬停/聚焦时用工具提示给出全文。人名不省略（取 `short_name`，≤ 8 个拉丁字符 / 4 个汉字·韩文字）。
6. **图标 + 文字**：图标永远在文字左侧，方向不随语言变（无从右到左语言）。
7. **字体烘焙约束**：用到的所有 i18n 字符都必须在图集里（`bake_font.py --check`）；界面中不得出现运行时拼出的新汉字。玩家自定义文本不存在（无文本输入，见 §2.1、新局种子）。
8. **探针**：`tests/probe/ui_text.lua` 对每个屏幕、每种语言、两种字体模式截图/断言：文本矩形不越出所属容器，`quad_count()` 不超 10,000 的 60%。

### 2.3 设置（`ui/settings.lua`）

左侧页签（LB/RB 或点击切换），右侧控件列。每页底部固定"恢复默认""返回"。

| 音频 | 主音量、音乐、环境、音效、界面音 | 滑块（步长 5%，键盘左右、手柄左右） |

| 输入-手柄 | 摇杆死区、扳机阈值、光标速度、自动焦点目标开关、校准（§7.3 末段） | 滑块、开关、按钮 |
| 改键 | §7.3 | 列表 + 三列 |

设置保存到 `saves/settings.sav`（经 `sys.save_write`），改动即时生效，`返回` 时落盘；"恢复默认"需确认对话框。

### 2.4 存档位

- 3 个槽位（`slot1..slot3`，对应文件 `saves/run_1..3.sav`），每槽 = 一局。只在时段边界（黎明、黄昏）自动存档，每个存档位保留上一个边界的备份（`run_N_prev.sav`）；中途退出，回来从最近的边界继续（PLAN §4.5、U9）。
- 槽位卡 480×88：头像最多 4 个（48×48）、第 N 天、幕、幸存人数、难度、游玩时长、保存时间；空槽显示"新局"。
- 操作：加载、删除（确认，长按 1 s 替代）。不提供任意时刻手动存档，也没有挂起存档；任何场景（含潜行副本）选择退出都只是确认后回标题，下次继续时从最近的时段边界（黎明或黄昏）存档开始，不再有"放弃本夜"一说（见 §12 U9）。槽位卡与详情里显示"最近存档点：第 N 天 黎明/黄昏"，并可选择读取该边界或其上一个边界的备份。

### 2.5 开发面板（`ui/devpanel.lua`，仅 `--dev`，F1 开关）

NARRATIVE §2.10 的工具。只需键鼠，不进入三条探针；手柄无入口。

页签：**事实**（黑板键值，可筛选）｜**账本**（行为记录，按角色/时间）｜**心理**（选一个角色，列全部压力/慰藉条目：来源、值、剩余衰减）｜**片段**（每个片段逐条件命中与否：✔/✘ + 当前值；按钮"强制触发"）｜**时间**（跳到第 N 天/时段，数字选择器）｜**其它**（显示性能、`quad_count`、`lua_heap`、切换覆盖层调试）。面板宽 520 靠右，高度满屏，半透明 α0.75，打开不暂停；只读为主，列表用 §4.8 的列表控件。

## 3. 虚拟分辨率与布局

### 3.1 基准与锚定

- 设计基准 1280×720。所有 HUD 元素用 `anchor = TL/TR/BL/BR/TC/BC` + 偏移，大于 1280×720 的虚拟屏幕不放大元素，只让世界视野变大。
- 居中的面板（背包、交易、设置等）：宽 ≤ 1152、高 ≤ 640，居中，周围留 ≥ 32 的边。
- 安全边距：16 px（家用电视过扫描友好，设置里不另提供）。
- 坐标一律写作 `(x, y, w, h)`，原点左上；锚到右/下的元素在表中按 1280×720 换算。

## 4. 控件库规格（`ui/widgets.lua`）

### 4.1 通用约定

- 皮肤图集 `assets/ui/skin.png`，只有全透明/全不透明像素；半透明靠 `ui.color` α。所有九宫格切片 `nine_slice(tex, sx,sy,sw,sh, l,t,r,b, …)`，下表写作"源尺寸 / 切角 l,t,r,b"。
- 控件状态集合：`normal / hover / focus / pressed / disabled`；`focus` 与 `hover` 可同时存在（以 `focus` 视觉为准）。聚焦视觉统一为 **2 px `accent` 外框 + 1 px 内侧亮边**，每秒微闪（减少闪烁选项下常亮）；聚焦环不占布局。
- 每个控件对象：`{id, rect, enabled, focusable, on_activate, tooltip_key, nav={up,down,left,right}}`；绘制在 `_draw()` 里调用，事件在 `_update()` 里读"动作"不读按键。
- 禁用 = `disabled` 色 + 图标上叠斜线；禁用控件仍可聚焦（为了看工具提示说明为何不可用），但激活时只发出 `sfx/ui_deny`。
- 鼠标：左键 = 激活（按下后在控件内松开才触发，`mouse_released`）；右键 = 取消/返回（面板上）或无效。键盘：方向键/Tab 导航、Enter/Space 激活、Esc 返回。手柄：十字键/左摇杆导航、A 激活、B 返回。

### 4.2 按钮 `Button`

| 项 | 规格 |
|---|---|
| 外观 | 皮肤 `btn` 32×32，切角 8,8,8,8；5 个状态在图集里竖排，各一块 |
| 尺寸 | 高 40（标准）/ 48（底栏）；宽 = `max(96, text + 32)`；两行文字时高度 +18 |
| 状态 | normal 底 `bg_hi`；hover 提亮 + 光标变手形（无硬件光标，则文字下划线）；pressed 内容下移 1 px、底变暗；focus §4.1；disabled §4.1 |
| 鼠标 | 悬停高亮，左键松开激活 |
| 键盘/手柄 | 聚焦后 Enter / A 激活；`pressed` 视觉持续 ≥ 80 ms |
| 变体 | 主按钮（`accent` 描边）、危险按钮（`danger` 描边，默认触发确认对话框）、文本链接（无底，只有下划线） |

### 4.3 图标按钮 `IconButton`

方形 48×48（也有 44、32 版本）；皮肤 `btn_sq` 24×24 切角 6；图标居中（32×32 或 16×16）；角标（红点 8×8、数字）可选。工具提示必有（图标含义 + 热键）。其余同按钮。

### 4.4 开关 `Toggle`

整行控件：左侧标签（自动换行，宽 = 容器 − 72），右侧 56×28 的滑槽：皮肤 `toggle` 56×28，旋钮 24×24。**开/关** 除了颜色外，旋钮位置与文字"开/关"（`f_s`，三语）同时标注。激活 = 翻转；键盘 Enter/Space，手柄 A；左/右方向键直接设为关/开。

### 4.5 滑块 `Slider`

槽 `slider_track` 24×8 切角 4,0,4,0，拇指 16×24，数值文字显示在右侧（`f_s`，宽 40）。

| 设备 | 操作 |
|---|---|
| 鼠标 | 按住拇指或槽任意位置拖动（`mouse_pos` 实时），松开提交；点击槽 = 跳到该位置；两端有 `−`/`＋` 16×16 小按钮（无滚轮替代） |
| 键盘 | 聚焦后 ←/→ 步长一档，Shift 十倍；Home/End 到端点 |
| 手柄 | 聚焦后 ←/→ 一档，按住连续（0.4 s 后每 80 ms 一档）；LT/RT 十倍 |

聚焦滑块时 ←/→ 被控件吞掉，方向导航仍可用 ↑/↓ 离开。

### 4.6 循环选择 / 下拉 `Cycle` / `Dropdown`

- **Cycle**（选项 ≤ 5）：`‹ 值 ›`，值文本居中，宽 ≥ 最长选项 + 64（按当前语言实测，切换语言重算）；两侧 24×32 箭头钮。键盘/手柄 ←/→ 切换；Enter/A 在末项后回绕。鼠标点箭头或点值（前进）。
- **Dropdown**（选项 > 5，如改键冲突选择、语言以外的长列表）：触发器与 Button 同款，右侧 ▾ 16×16。展开为模态小列表（`List`，最多 8 行，超出用 §4.8），焦点被捕获，B/Esc/点外部关闭；选择后焦点回触发器。

### 4.7 页签 `Tabs`

页签条高 40，每页签宽 = `max(96, text+32)`，皮肤 `tab` 24×40 切角 8,8,8,0；选中页签底色与内容面板连成一体并有 `accent` 上沿。**LB/RB 切换页签；键盘 Ctrl+Tab/Ctrl+Shift+Tab 或 `[` `]`；鼠标点击。** 页签条本身不参与方向导航落点（由 LB/RB 与鼠标覆盖），但在焦点组里登记为一个组件，↑ 从内容首行到页签条时聚焦当前页签，←/→ 换页签。超宽时页签文本换两行，不出现滚动。

### 4.8 列表 `List`（无滚轮）

| 项 | 规格 |
|---|---|
| 行 | 高 40（单行）或自适应（多行）；行皮肤 `row` 16×40 切角 4；奇偶行底色微差；选中行 `accent` 左条 4 px |
| 滚动条 | 右侧 16 px 宽；轨道 + 拇指（最小 32 px）+ 顶/底翻页箭头 16×16；点击轨道空白 = 翻一页；拖拽拇指；按住箭头连续滚动（0.4 s 后每 60 ms 一行） |
| 鼠标 | 点行选中；双击/再点 = 激活；拖拽拇指；点滚动条箭头；**没有滚轮**。另有"上一页/下一页"在 `focus` 的 `LB/RB`（无页签时） |
| 键盘 | ↑/↓ 逐行，PageUp/PageDown 翻页，Home/End，Enter 激活；聚焦行始终保证可见，必要时自动滚动 |
| 手柄 | 十字键/摇杆 ↑↓ 逐行；LB/RB 翻页（没有页签的页面）；A 激活；行内有多列可聚焦控件时 ←/→ 在行内移动 |
| 渲染 | 列表可视区用 `ui.clip`（**不嵌套**：同一时刻只允许一个裁剪区。列表内的行不再自行 clip，长文本在行内用省略；工具提示、下拉等弹出层在列表 clip 结束后再画） |

### 4.9 网格背包 `ItemGrid`

- 格 48×48，间隔 4，皮肤 `slot` 24×24 切角 4；物品图标 32×32 居中；右下角数量（`f_s`），重量过重的格子描 `danger`。
- 容器类型：个人背包（N×M，由背包等级定）、家里储物（分类页签）、容器搜刮（raid）、交易双方、快捷栏（4 格）。
- 两种操作方式并存，均必须完整可用：

| 方式 | 鼠标 | 键盘/手柄（非拖放，同一套） |
|---|---|---|
| 拖放 | 按住左键拖出 ≥ 6 px 开始拖拽，图标跟随光标，落点格高亮：可放 `ok` 框 / 不可放 `danger` 框；松开放置；落在不同容器 = 移动；Esc/右键取消 | – |
| 点击-点击 | 点一个物品 = "拿起"（格子变虚线，图标贴在光标上），再点目标格放下；右键取消 | 聚焦物品，A = 拿起，移动焦点到目标格，A = 放下，B = 取消放回 |
| 快速转移 | Shift+点击 或 右键菜单"转移" | 聚焦物品按 X（"转移到对面/背包"），Y 打开物品菜单（使用/丢弃/装备到快捷栏/拆分/详情） |
| 拆分/数量 | 右键菜单"拆分" → 数值选择器（§4.14） | Y 菜单 → 拆分 |

- 转移到"另一侧"的目标由上下文决定：搜刮时 = 背包、交易时 = 对方的货架或我方的货架、家里时 = 下一个储物容器。
- 满载拒绝：`sfx/ui_deny` + 红色重量条闪一下 + 通知"背包满了"。
- 悬停/聚焦物品 0.3 s 显示工具提示：名称、类别、重量、价值、说明、已知的制作用途。

### 4.10 进度条 `ProgressBar`

皮肤 `bar` 16×8 切角 2；填充整数像素；可带文字（`62%`）；种类：需求条（§3.4）、制作/搜刮进度（可中断，带取消键提示）、撬锁（附噪音等级图标）、预报可信度。进度条不可聚焦，除非其容器是按钮。

### 4.11 工具提示 `Tooltip`

- 悬停 0.4 s（鼠标）/ 聚焦 0.4 s（键盘、手柄）出现，移开/失焦消失；也可按 `info`（键盘 `H`，手柄 Y 在非背包上下文，鼠标无需）立即显示并常驻。
- 皮肤 `tip` 16×16 切角 4；宽 ≤ 360，自动换行，高度随内容；位置：目标右下 8 px，越界则翻到对侧，必须全部落在屏内。
- 内容结构：标题行（`f_b`）+ 正文（`f_s`）+ 可选底行（热键提示、"不可用原因"以 `danger` 色）。
- 唯一一个工具提示；不可嵌套；`ui.clip` 外绘制。

### 4.12 模态对话框 `Modal`

- 暗幕 α0.55 铺满；对话框居中，宽 480–720，皮肤 `panel` 48×48 切角 12。标题（`f_t`）、正文、按钮行（右对齐，主操作在最右、默认聚焦；取消在左）。
- 焦点捕获（§5.5）：打开时压入新焦点组，关闭时恢复；Esc/B = 取消；点暗幕 = 取消（危险操作除外，只允许点按钮）。
- 同一时刻只有一个模态；新模态请求入队，前一个关闭后弹出。

### 4.13 确认对话框与长按替代 `Confirm`

- 用于：结束白天、放弃本夜、删除存档、危险抉择（片段中的不可逆选项带 ⚠ 标记，仍走片段对话框，不叠确认框）。
- 按钮：`确认`（`danger` 描边）/ `取消`（默认聚焦为**取消**）。
- **长按替代**：打开"无障碍 → 长按替代"后，确认对话框不出现，改为在原按钮上长按（默认 0.8 s，可调 0.4–1.5 s）：按钮底部填充环形/条形进度，松开或移走清零；键盘按住 Enter，手柄按住 A，鼠标按住左键。快捷键直达版本（"长按 E 结束白天""长按 Back 结束白天"）总是长按触发且不弹确认——"长按"本身就是确认。

### 4.14 径向轮盘 `Radial`（`ui/radial.lua`）

| 项 | 规格 |
|---|---|
| 外观 | 圆心在屏幕中心（鼠标触发时在光标位置，贴边时平移入屏）；半径 112，内环 40；2–8 个扇区，每个扇区 = 32×32 图标 + 下方 `f_s` 标签；中心显示当前选中项名称；暗幕 α0.35；打开时游戏暂停（可选，默认"暂停"） |
| 用途 | 队友指令（Q）、系统轮盘（手柄 Back 短按）、交互方式选择（撬锁/破门）、可用菜单项 ≤ 8 的右键菜单 |
| 键盘 | 按下 Q 打开；方向键 / 数字 1–8 / WASD 选；Enter 或再按 Q 确认；Esc 取消。扇区排布固定（北=1 顺时针） |
| 鼠标 | 点扇区；点中心或外部 = 取消 |
| 手柄 | 左摇杆指向扇区（死区 0.4，指向扇区即高亮）、A 确认、B 取消；十字键也可选扇区 |
| 超过 8 项 | 不用轮盘，用列表式上下文菜单（§6.3） |

### 4.15 数值选择器 `Stepper`（交易数量、拆分等）

## 5. 焦点导航（`ui/focus.lua`）

### 5.1 数据结构

```lua
focus = {
  groups = {},         -- 栈：每个模态/面板压入一个 group
  current = nil,       -- 当前聚焦的元素
  visible = false,     -- 聚焦环是否显示（见 5.6）
}
group = { id, items = {}, order = 'spatial'|'list', default = elem, remember = elem, wrap = false }
elem  = { id, rect={x,y,w,h}, enabled, on_activate, nav = {up=,down=,left=,right=} }
```

每帧 `_draw()` 期间控件调用 `focus.register(elem)`（立即模式），`focus.begin_frame()` 清空当前组的 `items`；因此只有"这一帧被画出来的控件"可聚焦，隐藏、被裁出可视区的行自动不可聚焦；滚动列表对不可见行用"滚动到可见"代替跳过。

### 5.2 方向导航算法

输入方向向量 `d`（上/下/左/右四值之一）。令当前元素中心 `c0`，候选元素中心 `ci`，`v = ci − c0`。

1. **前向条件**：沿方向的分量 `a = dot(v, d)`；必须 `a > 0`。
2. **边距**：`gap = ` 沿方向两矩形边缘的间距（重叠取 0）；`off = ` 垂直方向的中心偏移绝对值。
3. **锥形过滤**：第一遍要求 `off ≤ 1.5 · (a + 8)`（约 ±56°）；若无候选，第二遍放宽到不限，但分数加 +400。
4. **分数**（越小越好）：

```
score = gap + 2.0 · off + 0.25 · a_center
        - (若候选与当前在同一行/列组 +0；跨组 +120)
```

其中 `a_center = a`（中心距离，用于打破近似平局）。若有 `elem.nav[dir]` 显式指定，直接采用，不计算。
5. **平局**：分数相差 < 1 时，优先"上一次从该方向进入过的元素"（焦点记忆），其次 y 小、再 x 小。
6. **回绕**：默认不回绕；列表、页签、循环选择在其内部自行回绕或夹到端点；`group.wrap = true` 的小菜单（轮盘外的 ≤ 6 项）上下回绕。
7. **输入重复**：方向键首次延迟 0.35 s，之后 0.09 s 一次；摇杆用同样节奏，阈值 0.6，仅取主轴。

### 5.3 焦点组与页签

- 一个屏幕 = 一个或多个 `group`（如设置：页签条组 + 页内容组 + 底部按钮组）。↑/↓ 在组间用 §5.2 的"跨组 +120"惩罚自然过渡，不另设按键。
- LB/RB（键盘 `[` `]`）切换当前页签：切换后焦点落到新页内容组的 `remember` 或 `default`。
- 带页签的面板里，LB/RB 永远是切页，不用于翻页（翻页用列表自己的 PageUp/PageDown；手柄在带页签的页里用右摇杆上下 = 翻页）。

### 5.4 默认焦点与焦点记忆

- 打开屏幕：焦点落在 `default`（主操作，如"继续""开始"）；只在 `visible = true` 时显示环（§5.6）。
- 每个 `group` 保存 `remember`：从子屏返回（关闭背包、关闭设置）时恢复到触发它的那个控件。
- 内容变化（删除行、物品被取走）：焦点移到下一个同类元素，没有则上一个，再没有则组默认。

### 5.5 模态焦点捕获

- `focus.push_group(g, {modal=true})`：之后方向/确认/取消只作用于栈顶组；下层组的控件仍被画，但 `register` 被忽略（不可聚焦、不响应鼠标悬停、不弹工具提示）。
- 栈顶组关闭 → `pop_group` 恢复下层的 `remember`。
- Esc/B 默认触发栈顶组的 `on_cancel`；没有 `on_cancel` 的模态不能被取消（如片段的必选项）。

### 5.6 鼠标悬停与焦点；最近设备

| 事件 | 行为 |
|---|---|
| 鼠标移动 ≥ 3 px | `last_device = mouse`：聚焦环隐藏；悬停元素获得 `hover` 高亮；**同时** `focus.current` 设为悬停元素（这样随后按键盘/手柄方向键时从鼠标所指处出发） |
| 键盘导航键 / 手柄方向键按下 | `last_device = keyboard / pad`：聚焦环显示；若 `focus.current` 为空或不在屏内，选 `default` |
| 鼠标点击 | 激活悬停元素（不需要先聚焦）；点空白处不取消聚焦 |
| 设备切换时 | 聚焦环显示/隐藏由 `kit_input.last_device()` 决定；提示栏图标同步切换（§9） |
| 手柄悬停光标（自由光标） | 与鼠标同样处理 `hover`，视作鼠标设备但提示栏仍显示手柄图标 |

规则：任一时刻只有一个视觉主体——"悬停"与"聚焦"重合时显示为聚焦。鼠标静止 3 秒不会取消悬停。

### 5.7 可达性校验

`ui/focus.lua` 提供 `focus.audit(screen)`：在探针里用方向键从默认焦点出发做 BFS，断言本屏所有 `enabled` 控件都可达，且没有"陷阱"（进得去出不来）。每个屏幕都要通过（GDD §3.5 输入覆盖校验）。

### 6.1 选人

- **选人方式**：点头像卡、点世界里的角色、键盘 `1–6`/`Tab`、手柄 LB/RB。

- 选中表现：脚下 1 格菱形黄圈（覆盖层组 8），头像卡加粗描边，世界内头顶有名字牌（`f_s`，可关）。

### 6.2 移动与指令（鼠标）

| 操作 | 家园 | 潜行 |

| 左键点地面 | 单键模式关：选中取消（点空地不移动）；开：移动 | 同左 |
| 右键点地面 | 移动选中者到该格（路径预览 §6.7） | 同左；当前为"潜行"则潜行走 |

### 6.3 上下文菜单内容规则

- 弹出位置：对象右上 8 px，越界翻转；条目 ≤ 8 → 用径向轮盘（手柄/键盘首选），> 8 → 列表式菜单。鼠标与键盘都用列表式（行高 36，宽 ≥ 192），手柄用轮盘或列表（沿用同一份条目表）。
- 条目表由 `view/interact.lua` 生成，**同一对象不同角色列表不同**，规则：

| 条件 | 规则 |
|---|---|
| 排序 | 默认动作（有且仅有一个）置顶并加粗；其后按"安全 → 有风险"；危险/不可逆的置底，前缀 ⚠ |
| 不可用 | 显示为灰色并附原因（"缺撬锁工具""Walt 不会修电器"），仍可聚焦以便读原因 |
| 特长标注 | 本角色擅长的条目旁加星标（"快 +30%"悬停可见）；有缺点惩罚者加黄色三角 |
| 噪音 | 有噪音的条目后附噪音等级图标（0–5 格），悬停时世界里预览噪音圈（§6.6） |
| 派活 | 家园里点工作台/床/病人：条目"让 X 来做"可切换执行人（二级菜单，LB/RB 或 ←/→ 在已选角色之间切换） |
| 数量 | 搜刮、挖雪等持续动作先给默认时长，不问数量 |

- 条目示例（家园）：工作台 → 制作…、修理、搬走；病人 → 治疗、喂药、谈话；废墟 → 清理；窗洞 → 钉板封堵；加热器 → 加燃料、检查。（潜行）容器 → 搜刮（响）、仔细搜刮（慢）；锁门 → 撬锁（静、慢）/ 破门（响、快，轮盘二选一）；NPC → 背后制服（打晕）、背后制服（杀死，⚠）、亮武器威吓、攻击。

### 6.4 手柄焦点目标自动选择

每帧（`view/interact.lua`）对当前操控角色计算：

```
候选 = 半径 R 格内、可交互、未被禁用、可通行到达的对象
R = 家园 3.0 / 潜行 2.5 / 战斗 4.0（用于攻击目标）
朝向向量 f = 左摇杆方向（摇杆偏移 > 0.3）否则角色当前朝向
score = d_tiles + 2.0·(1 − cosθ) − prio
  θ = f 与 (目标−角色) 的夹角；cosθ < −0.2 且 d > 1.0 → 淘汰
prio: 紧急(濒死队友/着火) 2.0；NPC 1.2；容器 1.0；门 0.8；工作台/床/设施 0.8；地面物品 0.5；装饰 0
```

- 取 `score` 最小者；**滞回**：已有焦点目标时，新候选需比它低 0.5 才切换；焦点目标丢失（走出 R+0.5）清空。
- 目标高亮：覆盖层组 9，目标格白框 + 浮标（目标上方 24 px 的箭头 + 名称标签 + 动作图标）。浮标显示默认动作与按键图标（A: 搜刮）。
- 多个并列：用 RB（循环下一个目标）/ LB（上一个）临时锁定，换目标 1.5 s 内不被自动选择覆盖；`focus_next/prev` 键盘 `.` `,`。
- **键盘同样使用此焦点目标**（F 对焦点目标交互），因此纯键盘也能玩；设置里"自动焦点目标"可关，关闭后键盘/手柄只能靠自由光标选择。

### 6.5 自由光标模式

- **手柄**：按住 LT 进入；左摇杆移动光标（速度 480 px/s，设置可调，边缘有加速曲线），A = 左键、X = 右键；释放 LT 或按 B 退出。光标显示为 24×24 十字准星 + 手柄按键提示。光标靠近屏幕边缘 48 px 自动平移镜头。
- **键盘**：`V` 切换；WASD/方向键移动（Shift 加速），Enter = 左键，右 Shift 或 Backspace = 右键；Esc/V 退出。
- 光标下的格/实体用悬停高亮（§6.6），并在提示栏显示可用动作。
- 自由光标时，世界内 WASD/左摇杆不移动角色（避免冲突）。

### 6.6 悬停高亮、工具提示与可交互标记

- **悬停高亮**：地面格 = 覆盖层组 15 浅白 α0.25 框；实体 = 1 px 白色描边（染色 shader 不可用，用覆盖层/精灵放大 1 px 的黑白描边副本）。
- **工具提示**：悬停世界实体 0.4 s 显示：名称、状态（NPC：睡眠/起疑/警觉；容器：未搜/已搜；门：关/上锁、锁的难度）、可用动作与噪音。
- **可交互物标记**（让玩家知道"这个能点"）：
  - 家园：可交互物不常亮；鼠标悬停才描边。设置里"显示交互点"开启后，所有可交互物头顶 12×12 圆点，未处理的任务（需要修/需要清理）用橙点。
  - 潜行：玩家 6 格内的未搜容器常亮微光点（α0.5，闪烁慢）；已搜的不显示。门：上锁红点、未锁绿点。
  - 开启"信息叠加"（`show_overlay_info`，键盘 N，手柄轮盘「信息」）时显示全部标记。
- 手柄焦点目标浮标见 §6.4。

### 6.7 路径预览

- 右键或移动指令按下前，鼠标悬停地面时（仅当选中者且 ≥1 步）：覆盖层组 6 画路径格点（每隔一格一个 8×8 菱形点，终点 16×16 圆环）；颜色：可达 `text` α0.5，需潜行/慢速 `accent`，不可达 `danger` 并在终点显示 ✖。

### 6.8 暂停时下指令的排队显示

- 暂停（`pause`）时仍可下指令；指令不立即执行，而是进队列，恢复时按顺序执行。每个角色的队列显示：
  - 世界内：从角色出发按顺序连成虚线，每个指令点标序号（1、2、3，16×16 圆标），终点带动作图标；
  - 头像卡：任务行显示"排队 ×2"；

### 7.2 冲突检测与保留键

**保留（不可改绑）**：Esc（取消/系统菜单）、鼠标左键（界面确认）、`ui_*` 导航（方向键、手柄 D/LS 与 A/B 在 U 上下文的含义）、手柄 Start（暂停）、F1/F11/F12。理由：保证任何时候都能退出、操作菜单、不会把自己锁死。

**冲突规则**：

| 动作所属上下文 → 与谁互斥 |
|---|
| G：与所有上下文互斥 |
| W：与 W、H、R、C 互斥（家园与潜行都包含 W）；与 G 互斥 |
| H：与 W、H、G 互斥（可与 R 复用） |
| R/C：与 W、R、C、G 互斥（可与 H 复用） |
| U/D/M：只与 U/D/M、G 互斥（可复用 W/H/R 的键，如 `Enter`） |

- 检测发生在改键提交时：同一设备列内，若新输入已被互斥上下文的另一个动作占用 → 弹出对话框三选一：**交换**（默认）/ **替换**（被替换的动作变为未绑定，若这使其在该设备上无任何入口则禁止替换）/ **取消**。
- 不可留空规则：每个动作在每个设备上要么有绑定，要么 §7.1 的"屏上入口"存在；只在单一设备有键位的动作（如键盘 `cursor_free`）必须在另两列有等价入口或屏上入口，否则保存被拒（`rebind.validate()` 同时用于探针的输入覆盖校验）。
- 修饰键：允许 `Shift+X`、`Ctrl+X` 组合（键盘），手柄允许 `LT+按键`（因 LT 本为修饰键），不允许 `LB+RB` 之类双键；组合键与单键同样参与冲突检测（`Shift+G` 与 `G` 视作不同，但 `G` 单键在判定时若 `Shift` 为 `run_hold` 的默认键会使 `Shift+G` 同时触发奔跑——判定规则：组合键优先，`run_hold` 的基础键 Shift 在组合键按下的那一帧不触发）。

### 7.3 改键界面流程（`ui/rebind.lua`）

```
设置 → 改键 页签
 ├ 顶部：设备页（键盘 / 鼠标 / 手柄，三选一的页签，LB/RB 不用，用 ←/→ 或点击）
 ├ 列表（行 = 动作）：动作名 | 上下文徽标 | 当前绑定（主）| 当前绑定（备）
 ├ 选中行 → [改键] [清除] [恢复此项默认]
 └ 底部：[全部恢复默认(确认)] [返回]

改键流程
 1. 聚焦某行主/备槽按 Enter / A / 点击 → 打开"按下新输入"覆盖层（模态）
    文本："请按下要绑定到「X」的{键/按钮}（Esc 取消，N 秒）"；倒计时条 5 s。
 2. 捕获：
    键盘  每帧轮询 kit_input.last_key()，忽略 Esc（=取消）、保留键；修饰键单独按下时等待 0.4 s 看是否有后续键。
    鼠标  轮询 `kit_input.last_mouse_button()`，忽略左键（保留）；允许右键与中键；屏上"取消"按钮代替 Esc 作为鼠标的取消入口。
    手柄  轮询 `pad.last_button()`（覆盖全部 17 个逻辑按钮，扳机按 `trigger_press` 阈值计入，故 LT/RT/L3/R3 均可捕获）；Start 取消（保留）；A/B 可绑定给 W/H/R/C 动作，在 U 内的含义不变；摇杆整轴只允许绑定 move_dir/camera_pan/光标类动作。
 3. 超时（5 s）或取消 → 关闭覆盖层，无改动，通知"已取消"。
 4. 捕获成功 → 冲突检测（§7.2）→ 无冲突直接写入；有冲突弹三选一。
 5. 写入后 `rebind.validate()`；失败则回滚并给出原因（"此动作在手柄上将无入口"）。
 6. 成功后行高亮 0.6 s，提示栏更新。设置 → 返回时落盘。
```

手柄校准：设置 → 输入-手柄 → "校准"：依次提示"左摇杆推到最上、最左…""按一下 A"，用 `pad.last_raw()` 读原始通道并 `pad.set_mapping`；每步 5 s 超时并可跳过；末尾"测试"页显示摇杆圆点、扳机条、按键灯。`pad.reset_mapping()` 为"恢复默认"。

### 9.2 提示栏生成规则（`ui/hintbar.lua`）

- 位置 (0,692,1280,28)，`bg` α0.70，不遮挡世界关键区域；模态打开时变为模态底部的提示行。
- 内容由"当前上下文栈顶"决定，每个上下文注册 `hints = {{action, text_key, show_if}}`，排序按注册顺序，最多 6 项，超过的并入 `…`（省略号 → 打开轮盘/帮助）。

| 上下文 | 提示项（按序） |
|---|---|
| 家园，无焦点目标 | 移动、暂停、选人、地图 |
| 家园，有焦点目标 | 交互（目标默认动作名）、指令、切换目标 |
| 潜行 | 移动、潜行/奔跑、交互（目标默认动作名）、队友指令、暂停、撤离（仅在出口区） |
| 战斗/暂停 | 攻击、制服、队友指令、继续 |
| 菜单/列表 | 确认、返回、翻页、详情 |
| 对话框 | 继续、选择 |
| 拖拽背包 | 放下、取消、转移 |
| 自由光标 | 点击、右键、退出 |

- 每项 = 按键图标 + `f_s` 文本；项间距 16；图标取当前设备主绑定，改键后立即更新；若一个动作同时有主/备绑定只显示主。
- 文本由 `i18n.t('hint.<action>')` 获取；动态目标名用参数（如 "搜刮 {target}"）。
- 提示栏宽度不足时，按优先级（越靠前越重要）丢弃末尾项而不是缩字号。
- "单手"提示（长按）：图标周围画圆环以表示长按。
- 鼠标设备：显示鼠标图标（左键/右键）+ 键盘热键的小标（可关）。

### 10.4 心理变化提示"原因"

- 数据来自 `sim/psyche.lua` 的条目列表（来源、值、衰减）；界面按 |值| 排序取前几条。
- 变化时：P1 通知，文本模板 `psyche.change`："{名字} 的状态 {旧}→{新}。因为：{原因 1}（{值}）{；原因 2}"，最多 2 条原因；通知右侧有"详情"按钮。
- 选中面板的心理行（§3.5）始终显示当前前两条；"详情"页列出全部条目：图标、来源文本（"三天前，米勒家的事"）、数值（▼ 12）、剩余天数、类别（压力/慰藉）。**每个条目的来源文本由 NARRATIVE §2.6 的条目带来的 `source_key` + 参数生成**，禁止界面里硬写。
- 崩溃前一天预警（NARRATIVE §2.6）：头像卡边框闪红、通知 P1"X 快撑不住了"、日志标记。
- 干预：详情页底部有"谈话/陪伴/给慰藉品"按钮（命令入口），并显示成功概率提示（"关系较好"/"陌生"，不给数字）。
- 温和叙述开启时，危机类条目的来源文本换成委婉的 i18n 键（片段字段 `text_soft`，键名后缀 `.body_soft`），详情页与通知一致。

## 12. 裁决结果（见 PLAN §10）

1. **头像与图标尺寸缺口**：PLAN D4 只有头像 96×96、图标 32×32。队伍卡需 48×48 头像与 16×16 状态/需求图标。建议在 ART-AUDIO 增加"头像缩略 48×48（30 张）"与"迷你图标 16×16（约 40 个）"，由工具 2× 最近邻下采样生成并允许手工修整；若不增加，则 UI 用 0.5 倍缩放绘制 96×96 / 32×32（本文已按此做兜底，但线条会糊）。
   → 裁决：PLAN §10 U1，同意：新增 48×48 头像缩略图与 16×16 迷你图标，补入 ART-AUDIO
2. **UI 缩放与 1080p**：本文把 `ui.set_scale(n)` 设为 `floor(H/720)`，1080p 得 n=1、虚拟屏 1920×1080（HUD 贴边，世界视野更大）。若希望 1080p 看起来与 720p 同样"大"，需允许 1.5× 非整数，违反 ENGINE-PLAN A1 第 4 条。请确认接受。
   → 裁决：PLAN §10 U2，同意：`n = max(1, floor(H/720))`，1080p 时 n = 1，可在设置里开大字模式
3. **世界缩放档位**：GDD 里有"缩放 Z/X、HUD ＋/−、R3 循环"，但 zoom 只取整数。建议只提供 `base` 与 `base+1` 两档（720p 下 1×/2×），R3 在两档间切换，不提供缩小。是否接受？
   → 裁决：PLAN §10 U3，同意：世界缩放两档（base 与 base+1）
4. **速度档位**：GDD 未写加速。本文加了 ⏸/1×/2×/4×（家园）与 ⏸/1×/2×（潜行），D7"1 秒 = 1 分钟"为 1× 基准。需确认是否允许加速，以及与 `bot`/探针的交互。
   → 裁决：PLAN §10 U4，修改采纳：家园 ⏸/1×/2×/4×，潜行只有 ⏸/1×
5. **长按 Back = 结束白天与 Back 短按 = 轮盘**：区分靠 0.4 s 阈值；与"长按 B 撤离（潜行）"不冲突，但需确认不要把 Back 长按放到潜行里。此外 `Start` 被当作保留的暂停键，系统菜单靠轮盘或 B（无可取消时），是否接受。
   → 裁决：PLAN §10 U5，同意：Back 短按开轮盘、长按结束白天；Start 为暂停，不可改绑
6. **`LT` 同时是自由光标与快捷物品修饰键**（GDD §3.2/§3.4）：按住 LT 即进入自由光标，此时十字键 = 快捷物品而非队友指令。可行但需确认不引起误触；备选：LT 轻点（<0.2 s）才是修饰键。
   → 裁决：PLAN §10 U6，同意：按住 LT 时十字键是快捷物品
7. **键盘纯玩的自由光标与焦点目标**：GDD 未规定键盘如何点任意格。本文新增 `cursor_free`（V）与让键盘共用"焦点目标"（F）。属新增动作，需确认并同步到 GDD §3.2。
   → 裁决：PLAN §10 U7，同意：新增 `cursor_free`（键盘 V），键盘与手柄共用焦点目标算法
8. **改键 API 缺口**：`kit_input` 只有 `last_key()`、`mouse_released(btn)`；没有"最后按下的鼠标键"和"本帧是否有任意输入"。鼠标改键需逐键轮询（可行）。`pad.last_button()` 是否包含扳机与摇杆按下？请 ENGINE-PLAN 确认（不含则 LT/RT/L3/R3 无法被改键捕获）。
   → 裁决：PLAN §10 U8，同意：引擎新增 `kit_input.last_mouse_button()`，`pad.last_button()` 覆盖全部 17 个逻辑按钮
9. **存档策略**：本文定 3 槽、每黎明自动存档 + 1 份备份、"保存并退出"产生一次性挂起存档、潜行中退出 = 放弃本夜。GDD 只说黎明自动存档。需确认"一次性挂起存档"是否符合设计意图（防刷事件）。
   → 裁决：PLAN §10 U9，不采纳挂起存档与"潜行中退出 = 放弃本夜"；只在时段边界存档（PLAN §4.5）
10. **框选不做**：GDD 未提框选；本文明确不做（手柄/键盘无法等价，违背 D8），改用 Shift 加选与"全选"。
   → 裁决：PLAN §10 U10，同意：不做框选，用 Shift 加选与全选
11. **轮盘暂停**：轮盘打开时默认暂停游戏（含潜行），GDD 允许"随时暂停"但未说"打开菜单时自动暂停"。已按"自动暂停"设计，可在设置里关闭。
   → 裁决：PLAN §10 U11，同意：打开轮盘或菜单时自动暂停（潜行与家园都适用）
12. **GDD §3.2 绑定补全产生的新增默认键**：`.` `,`（切焦点目标）、`V`、`N`、`H`、`=`/`-`（速度）、`Shift+G`（制服）、`Home`（居中）。若主代理偏好其它键，请在此处统一调整，不影响架构。
   → 裁决：PLAN §10 U12，同意新增默认键，完整绑定表以 UI-UX §7 为准
13. **`ui.clip` 不嵌套**：列表内不得再嵌套裁剪（本文已约束）；但"带裁剪的列表内弹出工具提示"需要先结束裁剪再画。已在 §4.8、§4.11 约定，实现者需遵守绘制顺序（先内容、后浮层）。
   → 裁决：PLAN §10 U13，同意：`ui.clip` 不嵌套，绘制顺序为内容 → 关闭裁剪 → 浮层
14. **文本输入缺失**：无自由文本输入，新局种子只能选择，无法"输入"分享种子。若要支持分享，建议使用 8 位数字（逐位选择器）。已按此设计。
   → 裁决：PLAN §10 U14，同意：无文本输入，种子逐位选择，不支持输入分享

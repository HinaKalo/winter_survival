## 1. 四大结局主屏与变体文案方向

### 1.1 `hold_home` — 守住家（对应 `kf_ending_home` + `bgm/ending_home`）
- **基础主句**：`"第三十天清晨，风停了。温度计停在零下二十二度，烟囱里的白烟直直往上走。"`
- **变体追加句**：
  - `warm`：`"内间木板墙把热气留住了。桌上的水壶没结冰。"`
  - `bare`：`"北墙窗板掉了一块，客厅椅子全劈了当柴，屋里还站着人。"`
  - `neighbors`：`"十点钟过后，米勒家和霍尔沃森老太太门前也铲出了窄道。"`
  - `watch`：`"戴尔在大门内侧坐了一宿，天亮时把两发空弹壳装回兜里。"`
  - `standing`：`"沃尔特打的松木支撑架吃住了屋顶积雪，门框一根没歪。"`

### 1.2 `underground` — 地下（对应 `kf_ending_bunker` + `bgm/ending_bunker`）
- **基础主句**：`"防爆门在身后合上，门栓落进槽里。走廊头顶的荧光灯嗡嗡作响，没有风。"`
- **变体追加句**：
  - `lt` / `full`：`"马什中尉按名单划掉最后一个名字，发给每人两条灰毛毯。"`
  - `sgt` / `expose`：`"后门仓库的出库单还在你们包里。派克站在通道口，没敢抬头。"`
  - `partial`：`"名单只够划掉一半。门合上时，剩下的人站在台阶外头哈气。"`
  - `betrayed`：`"二十七号清晨，岗哨换了生面孔。名单上没有你们的名字，只好连夜往回走。"`

### 1.3 `south` — 南行（对应 `kf_ending_south` + `bgm/ending_south`）
- **基础主句**：`"老旅行车在雪辙里晃出第二条街口，油表指针指在四分之三，后备箱里绑着备胎。"`
- **变体追加句**：
  - `all`：`"后座挤了三个人，膝盖顶着储物箱，谁也没提回头。"`
  - `split`：`"后视镜里，梧桐巷 41 号烟囱还在冒烟。留下的人没走到院门口。"`
  - `alone`：`"副驾空着，上面堆着两桶汽油和一箱罐头。"`
  - `pursued`：`"出镇口雪堤后亮起两盏车灯，一直跟过三号桥才掉头。"`

### 1.4 `fail` — 失败（对应 `kf_ending_fail` + `bgm/ending_fail`）
- **基础主句**：`"灶门开着，里面的灰已经凉透。窗缝吹进来的雪盖住了桌脚。"`
- **变体追加句**：
  - `froze`：`"最后一根木柴没点着，水桶底结了一整块实冰。"`
  - `scattered`：`"玄关挂钩空了。门没上锁，雪地上几串脚印分朝不同方向走远。"`
  - `fell`：`"门框锁舌崩在地上，背包里的罐头少了一半。"`

## 3. “你做过的事”账本回顾屏（`scenes/ending` 第三屏）

按 `WORLD.md §11.1` 与 `NARRATIVE.md §2.2` 原则 6/7，回顾屏**不显示道德分数或称号**，只并列展示可追溯事实：

1. **行为计数卡（仅三行客观统计）**：
   - 伸出过手的次数：`deeds.helped`
   - 夺走或伤害的次数：`deeds.harmed`
   - 死于你们手中的平民：`deeds.kills_civilian`
2. **具名住户命运列表（按玩家接触过的地点动态列出 `npc.<id>.fate`）**：
   - 示例格式（每行带地点 + 姓名 + 具体归宿）：
     - `suburb_house · 露丝·米勒`：`"春雪化开前搬去了圣马可教堂地下室。"` / `"二月中旬断了粮，再没人见过她开门。"`
     - `suburb_house · 莉莉·亨德里`：`"那瓶抗生素救了她，三月初还在教堂楼梯口玩绘本。"` / `"退烧药没等到，二月十四夜里停了呼吸。"`
     - `school · 加尔萨与八个孩子`：`"靠换来的柴火撑过了寒潮，体育馆墙上又多了两张蜡笔画。"` / `"麦片被拿走三天后，她带着孩子们连夜去了教堂。"`
     - `checkpoint_kilo · 马什中尉 / 派克军士`：`"派克被解除军需职务，掩体配给按人头重新登记。"` / `"哨站仓库夜里起过一次火，之后再没对外开放过。"`

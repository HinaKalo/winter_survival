## 1. 9 张关键帧插画分镜（`320×180`）

### 1.1 `kf_title` — 标题画面（梧桐巷 41 号雪夜）
- **构图与机位**：略高机位斜俯 2.5D 透视，镜头置于雪街对角线外侧。前景左下留出积雪灌木与电线杆暗部，作为主菜单按钮区安全底。
- **分层内容**：
  - **远景**：铅灰色暮雪天际线与被雪压弯的松树轮廓，无月亮，微弱天光。
  - **中景**：梧桐巷 41 号单层美式木屋，屋顶厚雪，烟囱冒出极细一缕灰白烟；一扇被木板钉过一半的客厅窗透出微弱暖橙光（全图唯一暖色锚点）。
  - **前景**：被雪半埋的铁邮箱与院门栅栏，几串深浅不一的脚印通向门口。
- **色板与光照**：冷青灰阴影为主（`ice[0..2]` / `snow[1..2]`），仅窗缝与雪面反光用 `fire[2..3]` 点缀，形成“外面 −30 °C、屋里一口气”的第一印象。
- **UI 安全区**：右侧 `x: 200..310`（1280×720 下为 `800..1240`）留暗色雪夜林影，放置标题与“新游戏 / 继续 / 设置 / 退出”。
- **音频提示**：`bgm/title`（低沉钢琴/合成弦乐）+ `amb/wind_exterior` 轻风声。

### 1.2 `kf_map` — 大地图背景（哈洛瀑布手绘战略图）
- **构图与机位**：正俯视桌面地图视角（略带倾斜纸张质感），四边为深色木桌与压图角铁/指南针边角装饰。
- **分层内容**：
  - **底图**：褪色牛皮纸与蓝灰色等高线地形，标出贯穿南北的冰封河道（通往 `river_dock`）、东西向主街与南山电台塔高地。
  - **地标暗影**：用极低对比度线稿暗示工业区仓库轮廓、圣马可教堂尖顶、县政府掩体标志（实际节点图标由 UI 层动态叠加）。
- **色板与光照**：去饱和纸灰与冷墨线，确保叠加的白色/橙色/红色节点图标与路线虚线高对比可读。
- **音频提示**：打开地图时仅保留当前时段环境音底噪。

### 1.3 `kf_dawn_report` — 黎明报告背景（窗台、收音机与热茶）
- **构图与机位**：室内近景平视，镜头面向结霜的木框窗台。
- **分层内容**：
  - **远景（窗外）**：灰蓝色的黎明雪院，天色刚泛白（05:00–06:00）。
  - **中景（窗台）**：一台接了临时铜线天线的老式短波收音机、一只缺口的搪瓷杯冒着细热气、半截烧剩的蜡烛。
  - **前景**：左侧留出大片暗木桌面与阴影区域，承载黎明报告文字列表（夜袭结果、搜刮收获、伤病与情绪变化、广播摘要）。
- **色板与光照**：窗外冷蓝与室内木色暗暖交界，收音机刻度盘一粒暗绿/琥珀指示灯。

### 1.4 `kf_coldsnap_a` — 寒潮过场 1：预报（电台与压境云墙）
- **构图与机位**：室内斜角越肩视角（未点名具体角色剪影），望向屋角桌上的收音机与结冰玻璃窗。
- **分层内容**：
  - **窗外**：地平线压来一堵铁灰近黑的暴雪云墙，树梢被狂风扯斜。
  - **室内**：收音机指示灯微闪，桌角摊开一张画着气温曲线的纸片（`−35°C` 字样不可辨但红笔下划线清晰）。
- **过场字幕方向**：`"无线电里的杂音突然拉长。霍布斯报出气压骤降的数字——明天入夜前，寒潮会压过北面的林线。"`

### 1.5 `kf_coldsnap_b` — 寒潮过场 2：风雪压城
- **构图与机位**：远景高机位俯瞰哈洛瀑布主街，暴雪斜打成 45° 白色噪点线。
- **分层内容**：
  - 街道被白雪吞没，路边废弃车辆只剩车顶弧线；远处圣马可教堂与居民屋顶几乎融进白雾。
  - 全画面仅有零星一两处极微弱的烟囱灰迹。
- **音频提示**：`amb/blizzard` 风啸拉高，压低其他所有声音。

### 1.6 `kf_ending_home` — 结局 1：守住家（`hold_home`）
- **构图与机位**：与 `kf_title` 呼应的同一栋房子（梧桐巷 41 号），视角略近、平视正面。
- **分层内容**：
  - 大寒潮刚过（第 30 天清晨），天空终于放晴，露出淡冷金色的冬日晨光。
  - 屋顶雪更厚，但所有窗户都用木板与防寒布封得严实；烟囱稳稳升起一道笔直白烟；门口台阶被人用铁锹清出一条窄道。
  - 若达成 `neighbors` / `standing` 变体，文字与尾声卡片补充邻里门前的脚印或加固木架细节。

### 1.7 `kf_ending_bunker` — 结局 2：地下（`underground`）
- **构图与机位**：基洛哨站县政府地下民防掩体厚重防爆门内侧仰拍。
- **分层内容**：
  - **前景**：半敞开的厚钢门与手电/应急灯投下的冷白光柱，地面是潮湿混凝土地砖。
  - **中景**：几只背着鼓囊背包的幸存者剪影走下水泥台阶，门口站着穿国民警卫队冬大衣的哨兵剪影。
  - **光照与色调**：荧光灯惨白、混凝土冰冷、没有阳光。

### 1.8 `kf_ending_south` — 结局 3：南行（`south`）
- **构图与机位**：公路低机位尾随视角，看向向南延伸的积雪双车道。
- **分层内容**：
  - 一辆修补过车门与防撞杠的旧旅行车/皮卡正沿着铲开一条窄辙的公路向南驶去，尾灯两粒暗红在雪雾里渐行渐远。
  - 后视范围可见车顶捆着油桶与备胎；两侧是无边白雪与枯树。

### 1.9 `kf_ending_fail` — 结局 4：失败（`fail`）
- **构图与机位**：室内静止特写，斜射冷光穿过破窗。
- **分层内容**：
  - 熄灭冷透的铁灶台，炉门微开着一撮灰烬；灶旁地板积了一层从窗缝吹进来的细雪；一只翻倒的空铁皮罐头。
  - **音频提示**：`bgm/ending_fail`（几乎全静，仅剩风声余韵，淡出）。

## 2. 开场序列分镜（第 1 天 06:00，梧桐巷 41 号）

开局不播放长动画，采用 **3 拍“关键帧 + 字幕卡”快切**（共约 12–18 秒，支持点击/按键跳过），直接落入可操作家园地图：

| 拍 | 画面 | 文字卡方向 | 音频 |
|---|---|---|---|
| **Beat 1（0–4s）** | 黑屏淡入 `kf_coldsnap_b` 局部裁切（暴雪后的小镇主街） | `"寒潮第 6 个月。电网停在去年十月，天然气管线早没了气。"` | `amb/wind_exterior` 渐入 |
| **Beat 2（4–9s）** | 切至 `kf_title` 房屋正面近景（门锁刚被撬开、院雪未铲） | `"你们四个人在梧桐巷尽头找到这栋空屋——瓦砾堵了一半房间，发电机坏着，灶台还是冷的。"` | 木门吱呀推开音效 |
| **Beat 3（9–14s）** | 淡出至实机家园画面（镜头锁定客厅灶台，4 名初始队员站在门口雪地里，室外温度计显示 `−15 °C`） | 队长短句提示：`"先把灶点起来，封住破窗。天黑前得弄清楚还缺什么。"` | 切入 `amb/home_day` |

## 3. 寒潮过场与结局演出流

### 3.1 寒潮到来过场（`coldsnap_cutscene`）
1. 触发时机：预报的寒潮当日 `dawn` 黎明报告结束、切入 `day` 之前。
2. 画面流：`kf_coldsnap_a`（2.5s，电台杂音 + 气温警报文字）→ 交叉淡化至 `kf_coldsnap_b`（3.5s，风雪压城 + 室外温度骤降数值）→ 淡入家园地图（全屋窗缝出现结霜/雪粒特效，室外进入极寒）。

### 3.2 结局与尾声演出流（`scenes/ending`）
严格遵循 `UI-UX.md §2.1` 与 `WORLD.md §11`：
1. **第一屏 — 结局定格**：全屏显示对应 `kf_ending_*`（1280×720），下方半透明暗底字幕给出主结局标题 + 变体副标题（如 `hold_home.warm` / `underground.lt` / `south.pursued` / `fail.froze`），播放对应 `bgm/ending_*`。
2. **第二屏 — 逐角色尾声卡片**：保留暗化 `kf_ending_*` 为底，逐一翻页/列表展示每名开局与中途入队角色的 `epilogue.<char>`（按 `WORLD.md §11.2` 优先级 1–5：`died` → `left` → `shaken` → `fulfilled` → `survived`，配该角色 96×96 对应情绪头像）。
3. **第三屏 — “你做过的事”账本回顾**：列出 `deeds.helped`、`deeds.harmed`、`deeds.kills_civilian` 与全部具名住户的 `npc.<id>.fate`（因你而活 / 因你而死 / 各自流离），最后给出“返回主菜单 / 解锁图鉴条目提示”。
